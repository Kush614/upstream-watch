API changelog

Keep track of changes to the Stripe API.

The source parameter on the Charges API is deprecated

Permalink

Breaking change. The source parameter on POST /v1/charges is deprecated and will be removed on 2027-03-01. Requests that send source will begin returning an error after that date.

Use payment_method instead. The value format is unchanged, so for most integrations this is a rename of the request parameter.

The radar_rules beta endpoint is removed

Permalink

Breaking change. The beta radar_rules endpoint is removed. Manage rules from the Dashboard instead. Integrations that never called radar_rules are unaffected.

New webhook event payout.reconciled

Permalink

A new webhook event payout.reconciled is emitted once a payout has been matched against your bank statement. No action is required; existing webhook subscriptions are unaffected.

The legacy_reporting endpoint is deprecated

Permalink

The legacy_reporting endpoint is deprecated and will be removed on 2027-02-01. Migrate to the Reporting API. Integrations that have never called legacy_reporting are unaffected.

Improved decline messages on card errors

Permalink

Card decline errors now carry a more specific decline_code. Existing codes continue to be returned, so this change is additive.

Added payment_method_options to PaymentIntents

Permalink

PaymentIntents accept a new optional payment_method_options hash for per-method configuration. This parameter is optional and additive.
